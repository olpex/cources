# Course Navigator

З наступного документу https://docs.google.com/document/d/1c8dGUmgmkALnHQlY7v21qN9odjqWvlJf2LYzqandmck/edit?usp=sharing 
будеш брати ті посилання, які знаходяться вгорі кожної з сторінок цієї презентації.

Тобто потрібно створити лендінг по курсу, який називається «Цифровий світ для початківців», а також для курсу, який називається «Штучний інтелект».

Розвиток кар'єри та професійного зростання. Там будуть інші посилання.

Задача — створити лендінг так, щоб викладач міг, клікнувши на ці посилання, відкривати ті презентації і демонструвати на екрані.

Одночасно на кожній із сторінок є нотатки до презентації. А ось нотатки до презентації мають бути відкриватися всередині самого проєкту, так щоб не переходити на Google Документи.

Прямо в проєкті, наприклад, як випадний документ, міг би бути реалізований даний функціонал.
